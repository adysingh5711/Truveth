# Truveth — Certificate Generation & Verification using Blockchain

Truveth is a **Blockchain-based Certificate Generation and Verification System** designed to ensure **tamper-proof**, **authentic**, and **verifiable** digital certificates creation.

By leveraging **smart contracts** and **decentralized blockchain infrastructure**, Truveth effectively eliminates issues like fake certificates and document manipulation.

---

## Live Link of Truveth:

https://truveth.vercel.app

---

## Key Features

- Prevents fake certificates using blockchain immutability
- Instant on-chain certificate verification
- Guaranteed authenticity and originality
- Decentralized and trustless architecture

---

## Technology Stack

- **Frontend:** React.js
- **Backend:** Node.js
- **Blockchain Integration:** Ethers.js
- **Smart Contracts:** Solidity
- **Development Tools:** Hardhat, Remix IDE
- **Blockchain Network:** Polygon (Amoy Testnet)
